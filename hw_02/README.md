# Змейка для arena.battlesnake.com

- ФИО: Евтушенко И. А.
- Группа: Б05-320

Сервер змейки по [Battlesnake API](https://docs.battlesnake.com/api) на Go без внешних зависимостей, кроме `golang.org/x/crypto` для сертификата. Своя реализация правил, перебор ходов и локальная арена для подбора весов.

Адрес змейки: `https://144-31-186-202.sslip.io`. Поддомен `sslip.io` сам указывает на IP сервера, сертификат выпускает Let's Encrypt.

## Запуск локально

Нужен Go 1.26 или новее.

```bash
go run ./cmd/server -http :8000          # змейка на http://localhost:8000
go test ./engine/                         # правила и короткие проверки поиска
```

Сервер укладывается в 500 мс на одном ядре: время на ход берётся из `game.timeout` минус оценка сетевой задержки (по полю `latency` из запроса) и запас 90 мс, но не больше 380 мс.

Локальная арена играет версии между собой, с простыми ботами и с внешними змейками по HTTP:

```bash
go run ./cmd/arena -a eng -b bot:greedy -games 200 -ms 40              # A против B, пары игр с переставленными местами
go run ./cmd/arena -a eng:Terr=12 -b eng -sprt 0,10 -games 2000        # SPRT: принять правку или отвергнуть
go run ./cmd/arena -a http://localhost:8000 -b eng -games 20           # внешняя змейка
go run ./cmd/arena -spsa Terr:2,Len:8,FoodDist:2 -games 3000 -out p.json  # подбор весов SPSA
go run ./cmd/arena -mode royale -a eng -b eng:Kill=300                 # режимы на 4: royale, standard, constrictor
```

## Как устроено

1. **Правила** (`engine/board.go`). Позиция — битовые маски 11x11 и кольцевые буферы тел, копируется без выделений памяти. Ход применяется по порядку официального движка: движение, голод, опасная зона, еда, выбывание (стены, тела, лобовые).
2. **Поиск** (`engine/search.go`, `engine/tt.go`). Итеративное углубление с альфа-бета: мы выбираем ход, ближайшие соперники отвечают худшим для нас образом, остальные (в режимах на 4) ходят простым правилом. Лобовое столкновение равных считается ничьей с отдельной ценой. Кэш позиций по Зобристу; когда головы рядом, перебор продлевается на ход (не больше двух раз на линии). Около 3 млн позиций в секунду, в дуэли 7–9 ходов вперёд за 300 мс.
3. **Оценка.** Территория по одновременному BFS от всех голов с учётом того, когда освобождаются клетки тел; спорные клетки достаются более длинной змейке. Плюс разница длин, расстояние до еды, когда голодны или короче соперника, запас здоровья, штраф за нехватку места. В опасной зоне royale голод считается с учётом её урона.
4. **Режимы** (`engine/profiles.go`). Свои веса для дуэли, standard на 4, royale и constrictor; сервер выбирает их по правилам игры и числу живых змеек.
5. **Hill-climbing** (`cmd/arena`). Каждая правка проверяется на сериях локальных игр: пары игр с одним зерном и переставленными местами, SPRT по Эло для решения «принять или нет», SPSA для весов. Арена считает и причины гибели (стена, тело, лобовое, голод) — по ним видно, что чинить.

## Эксперименты

Все игры локальные, змейка против своей версии с весами по умолчанию, 20 000 позиций на ход (одинаковый расчёт для обеих). Доля очков: 1 — победа (в режимах на 4 — первое место), 0,5 — ничья; Эло считается из доли. Проверка арены A/A: 400 дуэлей, доля 0,500.

Главные причины гибели в дуэлях — тело соперника или своё (около 80%, змейку отрезают) и лобовые с более длинным; в royale — голод в опасной зоне. В режимах на 4 главный выигрыш дал ранний поиск еды: порог голода 95 вместо 35 в standard и 95 при зоне в royale. Кэш позиций и ускорения BFS на силе не сказались (+5 и −7 Эло, в пределах шума), оставлены.

Против простых ботов (жадный к еде с проверкой тупиков): дуэли 40 из 40; на 4 (против трёх ботов) доля очков 0,91 в standard, 0,99 в royale, 0,83 в constrictor.

| Файл | Что внутри |
| --- | --- |
| `engine/board.go` | битовые маски, позиция, правила хода |

| `cmd/arena` | локальная арена, SPRT и SPSA |
