# Доказательный RAG по ТФКП

- ФИО: Евтушенко И. А.
- Группа: Б05-320

RAG по учебнику В. В. Горяйнова и Е. С. Половинкина «Лекции по ТФКП» (2025): ответ на вопрос с вариантами, краткое обоснование, ссылки на исходные `block_id`. Генерация — только Qwen3.5-4B. Подробности и эксперименты в [report.md](report.md).

## Запуск

Python 3.11, чистое окружение:

```bash
python -m pip install -r requirements.txt
python build_index.py --corpus /path/to/corpus.jsonl --output ./index --config config.json
LLM_BASE_URL=http://host:port/v1 LLM_MODEL=Qwen/Qwen3.5-4B LLM_API_KEY=... SUBMISSION_ID=... \
python predict.py --index ./index --questions /path/to/questions.jsonl --output ./answers.jsonl --trace ./trace.jsonl --config config.json
```

`build_index.py` скачивает с Hugging Face заявленные модели поиска и токенизатор Qwen (только для подсчёта токенов) и кладёт все файлы индекса в `--output`. LLM при сборке не вызывается. `predict.py` обращается в сеть только к `LLM_BASE_URL`, ручных действий не требует. Если переменные не заданы, используется локальный endpoint из `runtime.json`.

Эксперименты: прогон конфигураций из `configs/` (`configs/final.json` совпадает с `config.json`), затем оценка и строка для `experiments.csv`:

```bash
scripts/run_all.sh data/dev_questions.jsonl runs/dev configs/*.json
python scripts/evaluate.py --answers runs/dev/final_answers.jsonl --trace runs/dev/final_trace.jsonl \
  --questions data/dev_questions.jsonl --gold data/dev_gold.jsonl --corpus data/corpus.jsonl [--c-ref 2998] [--name final]
```

### Данные

Комплекта с корпусом и вопросами не выдавали, поэтому оба собираются из исходников скриптами:

- `scripts/make_corpus.py` строит `corpus.jsonl` из PDF учебника (sha256 `629f4b66…`): `python scripts/make_corpus.py --pdf Л_ТФКП_Горяйнов_Половинкин_2025.pdf --output data/corpus.jsonl`. Сам корпус в репозиторий не входит.
- `scripts/make_dev.py` строит `data/dev_questions.jsonl` и `data/dev_gold.jsonl` из `tfkp_15_qa.md`. Допустимые наборы источников заданы якорями «страница + начало блока» и разрешаются в `block_id` по корпусу.

### LLM для разработки

Локальный vLLM 0.33.0 на RTX 3060 12 GB, bf16 без квантизации, thinking выключен. Команда — в `runtime.json` (`access.dev_server`). На этой видеокарте понадобились `VLLM_USE_FLASHINFER_SAMPLER=0` (системный nvcc старый) и `--gpu-memory-utilization 0.85`.

## Архитектура

1. **Корпус.** Блок — абзац учебника, теорема или определение (до 1100 символов, длинные абзацы делятся по предложениям). Формулы линеаризуются по геометрии PDF: дроби, черта над символом, индексы, пределы.
2. **Индекс** (`build_index.py`). BM25 и `bge-m3` в двух вариантах — с нормализацией формул и без (для абляции), плюс токенизатор Qwen. Метки «Теорема 5.3», «(5.2)» и ссылки на них вычисляются из текста при загрузке.
3. **Нормализация формул** (`textnorm.py`). LaTeX из вопросов и Unicode-формулы корпуса приводятся к одной записи. К символам добавляются слова-описания (∂ → «частная производная», z̄ → «сопряжённое», ∮ → «интеграл»), формулы дают компактные токены (`∂f/∂zbar`).
4. **Поиск** (`rag.py`). Запросы: вопрос со всеми вариантами плюс вопрос с каждым вариантом отдельно. BM25 и dense объединяются через RRF.
5. **Контекст.** 6 лучших блоков. К первым трём добавляются соседние, если текст разорван, и блоки с определениями теорем и формул, на которые они ссылаются. Блоки упорядочиваются по тексту книги, токенов не больше 3500.
6. **Ответ** (`llm.py`, `predict.py`). Один вызов Qwen возвращает JSON: проверку каждого варианта (сначала рассуждение `why`, затем вердикт `ok`), отказ с причиной, запрос `need_search`, ссылки. Если модель просит недостающее или отвергает вариант со словами «во фрагментах этого нет», выполняется повторный поиск по её запросу или по тексту варианта и второй вызов. Решение пишется в `trace.jsonl` (`decisions`). Обоснование собирается из проверок вариантов, ссылки фильтруются по показанным блокам (не больше 3).
7. **Лимиты.** Перед каждым вызовом проверяются число вызовов, суммарный вход и выход и `вход + max_tokens ≤ 8192`. Расход берётся из `usage` ответа endpoint.
